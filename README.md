# Чудо Обувь — учебный проект с настоящим конструктором WinForms

## Что изменено

В этой версии элементы интерфейса созданы в файлах `*.Designer.cs`, а логика находится в соответствующих `*.cs`.

| Открыть в конструкторе | Что видно |
| --- | --- |
| `LoginForm.cs` | Поле логина, кнопки **Войти** и **Войти как гость** |
| `CatalogForm.cs` | Шапка с логотипом, поиск, категория, сортировка, контейнер для карточек товаров |
| `ProductForm.cs` | Фотография, описание, размеры, количество, добавление, назад |
| `CartForm.cs` | Таблица корзины, количество, клиент, подтверждение заказа |
| `OrdersForm.cs` | Таблица заказов, позиции, дата и кнопки управления |

**Почему карточки товаров не видны в конструкторе:** в конструкторе виден `flpCatalog`, куда приложение во время работы добавляет карточки для каждой записи из базы. Если добавить статические карточки в конструктор, они не смогут автоматически отображать все товары из SQL Server.

## Как открыть формы мышкой в Visual Studio

1. Распаковать весь архив — **не** отдельный `MainForm.cs`.
2. Дважды нажать `ChudoObuv.sln`.
3. В **Обозревателе решений** (Ctrl + Alt + L) открыть `LoginForm.cs`.
4. Нажать **Shift + F7** или ПКМ → **Просмотреть конструктор**.
5. Так же можно открыть `CatalogForm.cs`, `ProductForm.cs`, `CartForm.cs`, `OrdersForm.cs`.
6. В конструкторе нажать по кнопке, справа в **Свойствах** (F4) меняются `Text`, `Name`, `Location`, `Size`, `BackColor`.
7. **Не изменять вручную** `*.Designer.cs`: Visual Studio сохраняет в них положение элементов автоматически.

## Подключение SQL Server

1. Открыть SSMS.
2. Выполнить `Database/01_CreateAndFill.sql` целиком — будет создана **отдельная база** `ChudoObuv_DE_2027` с исходными данными.
3. **Внимание:** повторный запуск этого скрипта стирает изменения в этой учебной базе. Другие базы не затрагивает.
4. В `Db.cs` исправить имя сервера в `ConnectionString` — именно то, которое указано в SSMS.
5. В Visual Studio открыть проект, выбрать конфигурацию `Debug`, нажать F5.
6. Для проверки выполнить `Database/02_Check.sql`.

Проект использует **Windows Forms App (.NET Framework 4.8)** и `System.Data.SqlClient` без дополнительных пакетов NuGet. На компьютере должны быть установлены .NET Framework 4.8 Developer Pack и соответствующие компоненты Visual Studio.

## Как устроены файлы

- `Program.cs` — сначала запускается авторизация; по выходу снова открывает авторизацию.
- `LoginForm.cs` — проверяет логин.
- `CatalogForm.cs` — показывает товары и поддерживает совместную фильтрацию, сортировку и поиск.
- `ProductForm.cs` — размеры, количество, добавление в корзину/существующий заказ.
- `CartForm.cs` — корзина и подтверждение нового заказа.
- `OrdersForm.cs` — список заказов и управление их содержимым.
- `Db.cs` — все запросы и транзакции SQL Server.
- `Shared.cs` — данные пользователя и вспомогательные методы.

**Правила доступа:** гость может только просматривать. Покупатель оформляет заказ. Сотрудник открывает раздел заказов, создаёт заказы и добавляет позиции. Администратор также удаляет позиции и изменяет дату заказа.
