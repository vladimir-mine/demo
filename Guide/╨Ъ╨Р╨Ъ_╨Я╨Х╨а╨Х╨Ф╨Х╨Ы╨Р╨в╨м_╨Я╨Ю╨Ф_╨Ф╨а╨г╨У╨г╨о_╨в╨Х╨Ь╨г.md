# Как повторить проект на демонстрационном экзамене с другой предметной областью

Это **учебная памятка**, которую нужно потренироваться воспроизводить самостоятельно.

## 1. Какие части всегда одинаковые

- `LoginForm` — поле логина, кнопка войти / гость;
- `CatalogForm` — поиск, фильтр, сортировка, список объектов;
- `ProductForm` — подробности выбранного объекта;
- `CartForm` — выбранные записи и подтверждение;
- `OrdersForm` — список документов и состав;
- `Db.Read()` — один метод для SELECT;
- `Db.Run()` — один метод для UPDATE/DELETE;
- `Db.CreateOrder()` — транзакция создания документа и его строк.

## 2. Что меняется

| Магазин обуви | Другой вариант |
| --- | --- |
| Products | Books / Services / Parts / Equipment |
| Categories | Жанры / типы / категории |
| Sizes, Stock | Экземпляры / остатки / доступные варианты |
| Orders | Выдачи / записи / заявки |
| OrderItems | Строки выдачи / заказа / заявки |
| Manufacturer | Автор / мастер / поставщик (если есть) |

Не нужно создавать размеры для предметной области, в которой их нет: таблицы и связи должны соответствовать заданию.

## 3. Порядок действий

1. Прочитать поля Excel и выбрать сущности.
2. Создать БД в SQL Server: сначала справочники, затем основные таблицы, затем таблицы-связки.
3. Добавить `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE` для необходимых связей.
4. Перенести данные, проверить количество строк и корректность ссылок.
5. Открыть WinForms-конструктор и разместить поля на пяти формах.
6. Сделать простые SELECT-запросы для списков.
7. Реализовать подробности, создание и редактирование в отдельных методах.
8. Проверить права пользователей, пустые значения, нехватку остатков, отмену.
9. Сохранить SQL вместе с данными, сделать ER-диаграмму и README.

## 4. SQL и C# для запоминания

```sql
CREATE TABLE Categories (
  Id int PRIMARY KEY,
  Name nvarchar(100) NOT NULL
);

CREATE TABLE Products (
  Id int PRIMARY KEY,
  Name nvarchar(200) NOT NULL,
  CategoryId int REFERENCES Categories(Id)
);
```

```csharp
DataTable table = Db.Read("SELECT * FROM dbo.Products");
gridProducts.DataSource = table;
```

```csharp
DataTable table = Db.Read(
    "SELECT * FROM dbo.Products WHERE Name LIKE @search",
    Db.P("@search", "%" + txtSearch.Text + "%"));
```

```csharp
Db.Run("UPDATE dbo.Products SET Name=@name WHERE Id=@id",
    Db.P("@name", txtName.Text), Db.P("@id", selectedId));
```

Для каждой новой темы надо изменить названия таблиц, столбцов и особенности правил, например расчёт цен и доступность товара. Копировать SQL без адаптации нельзя.
